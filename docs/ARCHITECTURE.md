# 架构与所有权

应用只有一个 Xcode 应用目标和一个原生测试目标。当前实现位于 `App/`，不恢复旧 SwiftPM 宿主、动态扩展运行时或公共 SDK。

## 宿主与模块

- `AppDelegate` 负责组装：安装模块回调、先连接消费者再启动模块、先断开消费者再停用模块，以及菜单、设置和退出。模块准备早于窗口内容创建。
- `IslandWindowController` 管理窗口、显示器、空间可见性与共享指针采样；SwiftUI 负责渲染和上报交互、动画完成。
- `AppState` 管理模块选择、呈现、导航、交互保持和宿主偏好。窗口管理、呈现策略和内容保持分离。
- `NativeModuleRegistry` 由应用持有，协调编译内置模块的启停；独立 AppState 不隐式操作全局管理器。
- `ModulePresentationBridge` 连接音乐、Agent 和已启用日历的权限消费者，合并变化并在停用时解除订阅，窗口层不重复订阅。
- `ModuleRefreshScheduler` 提供公共刷新设施；模块拥有业务调度和取消。可见性从传入的活动快照取得，诊断耗时不代表网络完成时间。

停用模块必须停止其生产者与消费者、释放观察者和定时器，并拒绝旧异步结果；隐藏页面不等于停用。模块不能停止应用拥有的公共设施。偏好、用户内容和最近有效快照可以保留。已开始且不可中断的 Apple Events 或文件操作按实际完成结果收尾，不能假装立即取消。

Tools 停用可能失败：若保持唤醒断言未成功释放，保留启用状态、错误和重试入口。正常设置入口在修改呈现与持久化状态前检查停用结果；注册表也会修正绕过入口的失败停用。

## 权限、偏好与本地化

`PermissionState` 是共享权限快照与请求／回读的所有者，不轮询、不自动申请权限。设置在显示、应用激活和显式授权完成后刷新；位置授权回调不等于采样位置。日历与通知只在启用时消费权限状态。

偏好按域隔离。天气单位由 `WeatherPreferences` 持有；设置恢复使用页面的同一个 AppState、存储和域名，保留恢复范围、撤销和缺失键语义。登录启动状态在写入成功或失败后都从 ServiceManagement 回读。

`L10n` 与根视图共享语言偏好。协议字段、标识符和用户内容不翻译。天气保存条件码和时区等原始数据，切换语言不需要重新请求网络。灵动岛及其浮层在自身边界内使用深色外观，普通设置窗口遵循系统外观。组件规则见 [设置约定](SETTINGS.md)。

## 呈现与交互

宿主统一管理悬停、拖动、控制器交互、短期保护与收起。保持令牌按所有者独立释放，重复或过期释放不能影响其他交互。隐藏宿主必须清理监听器、计时器与待处理输入。

窗口视口在动画前扩展，所有当前屏幕动画完成后才缩小；中断回调不能完成新的动画。退出中的内容立即停止接收输入和页面自有工作。减少动态效果、动画速度与省电设置由同一策略处理。

从岛内打开独立窗口时使用统一交接：未锁定的岛收起，但不禁止后续悬停和主动导航；已锁定的岛保持展开。文件选择只返回捕获的源页面，新导航和新交接使旧返回意图失效。外部应用／URL 仅在最新打开成功后收起，不自动返回。控件、浮层、共享和原生窗口各自释放自己的保持与资源会话。

## 媒体与文件生命周期

- 媒体完整快照替换旧值，增量快照保留省略字段、删除显式 null。播放位置按源时间戳和速率投影；达到本地时长不等于播放器已停止。
- 媒体流按代次独占，断线退避；按字节分帧，避免拆坏 UTF-8。控制进程有输出上限、超时和退出清理。新流更新覆盖旧校准结果，不能发布过期状态。
- 暂存架区分引用与受管副本。普通文件删除只移除条目；受管删除经串行后台队列执行，成功后移除条目，失败保留重试。队列复核置顶、保留期和路径所有权；停用取消未开始的请求，已开始的删除按结果收尾。
- 用户删除先进入持久化的十秒撤销事务，期间不删除文件；撤销或到期前停用恢复可见性。清空只作用于确认时捕获的条目。
- 拖出、复制和共享使用独立临时副本，不转移原文件或受管文件。副本由租约持有，最后一个租约结束后保留 24 小时；过期回收不遍历符号链接目录。共享准备成功不等于 AirDrop 已送达。
- 拖动保持与异步导入分开管理，导入完成不能解除新的拖动或其他控件保持。提前打开暂存架复用宿主指针采样，只读拖放类型元数据，不读取内容、不申请权限。
- 提词器草稿与已应用文稿分开持久化；完成应用草稿，普通关闭保留草稿。阅读检查点按文稿身份记录，恢复时保持暂停，不自动创建音频资源。全局快捷键只在启用时注册，冲突时撤销整组。

Agent 的原会话、通道、审批和消息确认边界见 [Agent 接入](AGENT.md)。排序组件的适配与持久化语义见 [排序组件](REORDERING.md)。

## 验证边界

原生测试针对真实内部协作，在文件、网络、时钟、权限与硬件边界注入受控替身。便携测试不能证明 AppKit、SwiftUI、系统媒体或真机交互有效。构建、测试与人工验收分开记录，不把历史成功次数当作当前结果。来源修订和许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
