# 真机验收清单

自动测试与构建不证明真实刘海、透明度、辅助功能、播放器、权限或多显示器行为。以下由用户在自己的设备上按涉及模块检查；它是当前检查清单，不是已通过记录。

默认 `test.sh` 和 `test.sh --full` 只做核心行为验证，不操作桌面。窗口／焦点自动回归使用独立的 `test.sh --ui`，需明确安排可被窗口、文件面板和模拟输入打断的时段，不得自动附带执行。UI 回归通过仍不替代下面的视觉和真实权限验收；分别记录核心、UI 回归和人工验收的状态，未执行项不能记为通过。

## 宿主、设置与排序

- 检查紧凑／展开／完整页面、快速反向切换、鼠标移出、固定展开、全屏隐藏、Spaces 与显示器切换；旧动画或窗口回调不能弹回旧页面。
- 在浅色／深色系统外观下检查岛内浮层和普通设置窗口；减少动态效果、省电设置应遵循预期。
- 打开设置、文稿编辑、文件选择和 Quick Look，再最小化、激活、关闭；悬停仍可用，新导航不被旧窗口完成回调覆盖。锁定时窗口不应缩小到原生最小尺寸以下。
- 在中英文、窄宽窗口下检查控件可读性、数值输入、滑块、恢复与撤销；缩放不丢输入，过期编辑不覆盖恢复结果。
- 模块排序检查连续拖动、反向、首尾、Esc 和移出；悬停完成的换位即持久化，取消不回滚。确认开关、详情、右键及 VoiceOver 操作仍独立可用。
- 逐项停用模块，确认相关工作停止且设置／内容保留。授权撤销、重新授予、睡眠恢复和重启后检查权限回读，不应在启动或浏览设置时自动弹授权。

## 音乐与工具

- 从播放到一半的曲目开始，检查暂停／恢复、前后拖动进度、快速切歌、切换播放器与迟到封面；未知位置不能显示为归零，拖滑块不能切页或收岛。
- 检查主页标题、紧凑音乐与展开封面的不同导航行为；关闭紧凑音乐不应关闭主页与播放页。
- 播放模式、网易云收藏和失败提示以播放器实际状态核对；无权限或未知状态不能显示已完成。
- 保持唤醒检查到期、手动停止、无限时长、停用与失败重试；不把断言释放失败当作已停用。
- 键盘清洁检查普通键、修饰键、媒体键、按住键后结束、鼠标退出入口、权限失效和睡眠中断。单独确认硬件电源／Touch ID 限制；不要依赖键盘快捷键退出。

## 暂存架、提词器与信息模块

- 暂存架检查真实文件拖入／拖出、承诺文件、剪贴板、共享和 AirDrop；引用原文件不可被删除或移动。检查十秒撤销、到期删除、置顶变更、失败重试和停用时未完成操作。
- 检查屏幕边缘提前打开、跨目标拖动、导入完成、搜索与多选；导入结束不能释放另一拖动或浮层的保持。共享准备不等于接收端已收到文件。
- 提词器检查草稿关闭／继续编辑／应用、阅读恢复、段落定位、语音跟读与全局快捷键冲突；恢复保持暂停，停用释放音频资源。
- 日历检查跨日／时区、授权恢复和提醒去重；天气检查手动城市、定位拒绝与网络失败保留旧数据；通知检查过滤、清空、暂停和权限撤销。

## Agent

- 默认开启模块不安装 Hooks；模块或 Codex 开关关闭后停止真实来源 I/O，管理入口仍可用。原生覆盖恢复时，已启用的后备应停止；禁用后备不应断开原生订阅。
- 用已有会话核对状态、进度、计划、子代理归属和原会话跳转。近期目录不能被当成正在执行，问题在 Codex 回答后应正确解除。
- 分别检查 Desktop 与已有 CLI daemon 支持的发送／引导／排队；核对目标、轮次、顺序及最终实际接收，不能只看本地 ACK。断线或确认丢失时草稿保留，不自动重发。
- 使用真实人工审批请求检查命令／路径内容、允许／拒绝／取消轮次、多请求和过期处理；不受支持的请求留在 Codex。测试夹具、Shell 标记和辅助程序产出都不是岛内点击闭环。
- Hooks 的安装、信任、启用与运行时刷新分别确认。移除不影响其他工具配置，未确认的 Desktop 刷新不能显示为已完成。
